# テストプレイ・検証手順

## 1. コンテナの起動
以下のコマンドで必要なサービス（エンジン、CLI、フロントエンド）を起動します。

```bash
docker compose up -d
```

## 2. フロントエンドの検証
ブラウザを開き、以下のURLへアクセスしてください。
- URL: `http://localhost:5173`
- 確認事項: 画面に「Alchemy Incremental」が表示され、コンポーネントが配置されていること。

## 3. バックエンド・エンジンの検証
以下のコマンドでエンジンロジックの動作検証を行います。

```bash
docker compose exec -T cli npx tsc && node src/index.js
```
