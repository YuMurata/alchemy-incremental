# 02_詳細設計書

## 1. API型定義 (TypeScript)
### `/api/mix` (POST)
```typescript
interface MixRequest {
  items: string[]; // 素材IDの配列
  spiritId: string; // 使用する精霊ID
}

interface MixResponse {
  success: boolean;
  resultItemId?: string; // 成功時のみ
  error?: string; // 失敗時のみ
  spiritExpGain: number; // 精霊の獲得経験値
}
```

### `/api/status` (GET)
```typescript
interface GameStatusResponse {
  inventory: { itemId: string; count: number }[];
  spirit: { id: string; level: number; exp: number };
  unlockedRecipes: string[];
}
```

## 2. 状態管理ストア (Context)
```typescript
interface GameStore {
  items: Record<string, number>;
  spirit: { level: number; exp: number };
  uiState: 'Idle' | 'Playing' | 'Success' | 'Failure' | 'Result' | 'Menu';
  // 更新アクション
  mix: (items: string[]) => Promise<void>;
}
```

## 3. コンポーネントProps定義
- **Overlay**: `state: GameStore['uiState']`
- **Mixer**: `onMix: (items: string[]) => void`
- **Inventory**: `items: Record<string, number>`, `onSelect: (id: string) => void`
