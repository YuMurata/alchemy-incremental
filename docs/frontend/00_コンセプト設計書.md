# 00_コンセプト設計書

## 1. 目的
本プロジェクトのフロントエンドにおけるUI/UX体験と、開発・保守方針の確定。

## 2. 合成のコア体験
- **成功時**: 派手な演出で「未知の素材発見」の喜びを強調。
- **失敗時**: 演出を簡略化し、すぐ次の試行へ移れるテンポの良さを重視。
- **インフレとステップアップ**: 精霊やホムンクルスといった強化要素を軸に、ランクアップの節目を設けて成長を実感させる。

## 3. デザインと操作性
- **デザイン**: 伝統的な錬金術師の作業机をテーマにした「Crafted Modern」。
  - ベースカラーには深海のようなネイビー（#1a1f26）と羊皮紙のようなマットな質感（#e8e0d3）を組み合わせる。
  - タイトル等の見出しはセリフ体（Playfair Display）、本文はサンセリフ（Inter）を用い、モダンさと伝統的な質感を両立させる。
- **操作性**: デスクトップとモバイルの両立（レスポンシブ）。
- **署名要素 (Signature)**: 「The Living Recipe」。合成ボタン押下時に、素材が中央へ物理的に吸い込まれるようなアニメーションを実装し、成功時はゴールドの光、失敗時は静かにくすぶる反応で結果を示す。

## 4. 品質と開発方針
- **品質**: TDD (Test-Driven Development) を採用し、ロジックの信頼性を最大化する。
- **保守性**: 実装のロジックとUIを完全分離し、テスト可能な設計を維持する。
