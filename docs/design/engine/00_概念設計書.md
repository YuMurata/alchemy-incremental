# 00_概念設計書: Alchemy Incremental

## 1. ゲームコンセプト
「錬金術の奥深さと、インクリメンタルな成長を融合させる」

プレイヤーは、無から有を生み出す錬金術師として宇宙の真理を解き明かす旅に出ます。
小さな素材から始まり、やがて星々を合成し、最終的には宇宙そのものを自らの手で錬成するような壮大な成長を体験してください。
この世界では「再創世（レ・ジェネシス）」という現象が繰り返されます。宇宙が限界を迎えるたびに、すべてを分解し、再び創造することで、あなたの力はさらなる高みへと進化し続けます。

## 2. ターゲット体験
- 試行錯誤して新しいレシピを発見する「探索の喜び」。
- 放置していても数値が跳ね上がる「成長の快感」。
- 再創世によって過去の苦労が資産に変わる「メタ成長」。

## 4. 開発理念
- 「システムは小さく、コンテンツは膨大に」
- シンプルな合成ルールを維持しつつ、レシピ数（300個）による圧倒的なボリュームで世界観を構築する。

## 5. ゲーム内用語定義
プロジェクト全体で使用する共通言語です。

| 用語 | カテゴリ | 役割・定義 |
| :--- | :--- | :--- |
| **再創世 (レ・ジェネシス)** | リセット | 宇宙が限界に達した際に全てを分解・再構築する行為。**レシピ発見状況を含む全ての進行状況が初期化される。** |
| **記憶の結晶** | 資産 | 再創世時に釜に残っている、かつての宇宙の断片。永続的な強化に使用。 |
| **触媒** | コスト | 合成の効率化や自動化に用いる補助素材。 |
| **ゴールド** | 通貨 | 合成や設備のランクアップ等に使用する汎用通貨。 |
| **素材** | 資源 | レシピ合成に必要な材料全般。 |
| **マスターレベル** | 成長 | 合成回数に応じて向上する、各レシピごとの習熟度。 |
| **釜 (Cauldron)** | 設備 | 合成を行うための基盤。ランクアップにより合成効率が向上。 |
