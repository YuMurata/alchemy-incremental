# 00_概念設計書: Alchemy Incremental
(最終目標：PLiCy公開)

## 1. ゲームコンセプト
「錬金術の奥深さと、インクリメンタルな成長を融合させる」

プレイヤーは、無から有を生み出す錬金術師として宇宙の真理を解き明かす旅に出ます。
小さな素材から始まり、やがて星々を合成し、最終的には宇宙そのものを自らの手で錬成するような壮大な成長を体験してください。
この世界では「再創世（レ・ジェネシス）」という現象が繰り返されます。

## 2. ターゲット体験
- 試行錯誤して新しいレシピを発見する「探索の喜び」。
- 放置していても数値が跳ね上がる「成長の快感」。
- 再創世によって過去の苦労が資産に変わる「メタ成長」。

## 3. インフラ・構成方針
- **最終公開先**: PLiCy (HTML5ゲーム投稿プラットフォーム)。
- **確認環境**: GitHub Pages (外出先確認用の静的サイトホスティング)。
- **データ管理**: ブラウザ内LocalStorage/IndexedDBによるセーブデータ永続化。
- **統合**: EngineロジックをUIコンポーネントに直接統合し、単一のリポジトリとしてビルドを行う。

## 4. 開発理念
- 「システムは小さく、コンテンツは膨大に」
- シンプルな合成ルールを維持しつつ、レシピ数（300個）による圧倒的なボリュームで世界観を構築する。
