# 03_詳細設計書: Alchemy Incremental

## 1. 命名規則
- **レシピID**: `r_{tier}_{index}` （例: `r_01_001`）
- **素材ID**: `m_{name}` （例: `m_water`）

## 2. 関数インターフェース定義 (TypeScript)

```typescript
// 素材のインスタンス (合成や所持数で使用)
interface Material {
  id: string; // m_xxx
  amount: number;
}

// 素材のマスター定義 (DBから読み込む)
interface MaterialMaster {
  id: string;
  nameKey: string;
  baseValue: number;
  tier: number;
}

// レシピの定義
interface Recipe {
  id: string; // r_xxx_xxx
  ingredients: Material[];
  output: Material;
  baseTime: number;
  masteryPoint: number;
}

// 合成エンジンの主要API
interface SynthesisEngine {
  // 生成レートの計算 (System設計書 2.1準拠)
  getProductionRate(recipe: Recipe, masteryLevel: number, coreBonus: number): number;
  
  // 合成実行 (結果をJSONで返す)
  synthesize(recipe: Recipe): SynthesisResponse;
  
  // 再創世の実行 (System設計書 4準拠)
  resetUniverse(): void;
}

// レスポンスのJSON構造
interface SynthesisResponse {
  success: boolean;       // 成功か失敗か
  message: string;        // 表示用メッセージ
  data?: {                // 成功時にのみ返るデータ
    output: Material;
    consumed: Material[];
  };
  error?: {               // 失敗時にのみ返る詳細
    code: string;         // "NOT_ENOUGH_MATERIALS", "INVALID_RECIPE" など
    missingMaterialId?: string;
  };
}
```

## 4. レシピ構成の密度設計
- ランクごとのレシピ数 (総数 300)
    - Rank 1: 4個
    - Rank 2: 6個
    - Rank 3: 10個
    - Rank 4-6: 16, 24, 32個
    - Rank 7-9: 40, 48, 56個
    - Rank 10: 64個

## 5. 合成制約ルール
- **素材数**: 1回の合成には必ず 2 つ、または 3 つの素材を使用すること。
