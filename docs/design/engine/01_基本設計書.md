# 01_基本設計書: Alchemy Incremental

## 1. コンセプト
- 錬金術をテーマにしたインクリメンタルゲーム。
- 「レシピを埋めること」が最大の楽しさ（300個のレシピコンプリート）。
- コンテンツ（レシピ）の充実を優先し、システムは拡張性を重視した「ヘッドレス」設計とする。

## 2. コアサイクル
1. **採取・合成**: 素材を錬金釜に入れ、新しいレシピを発見・合成する。
2. **貢献・ブースト**:
    - **フェアリー**: ゴールドを捧げ、素材の自動売却や「妖精の粉」を得る。
    - **エレメンタル**: 素材を捧げ、錬成物の品質（価値）を高める。
3. **設備強化**: 「妖精の粉」で錬金釜を強化し、上位レシピの錬成を可能にする。
4. **ホムンクルス**: レシピの自動合成と釜の管理を代行。
5. **再創世（レ・ジェネシス）**: 宇宙の限界で全てを分解し、「記憶の結晶」を得てメタ成長する。

## 3. 数値成長・バランス設計
- **指数成長**: 合成物の上位階層ほど価値が乗算的に上昇する。
- **錬金ポイント (AP)**: 錬金（成功で価値分、失敗でも半分）により蓄積。
    - **APの効果**: 全レシピ共通の「錬金術師の腕前」。錬金時間の短縮と成功率の向上。
- **錬金レシピ本**: 
    - 試行錯誤の記録・直接錬成・不足素材の自動錬成（連鎖錬成）機能を提供。
- **マスターレベル (ML)**: 同一レシピの合成回数に応じて向上。
    - **MLの効果**: そのレシピの「産出量増加」と「品質ボーナス」。
- **フェアリーの自動売却**:
    - フェアリーによる自動売却は手数料が必要。
    - **交渉術 (Upgrade)**: フェアリーとの交渉レベルを上げ、手数料を低減・売却価値を向上させる。
- **触媒システム**:
    - 素材Aを必要個数とゴールドで対価に「触媒A」へ変換可能。
    - **触媒の効果(無限化)**: 触媒を所持している間、素材Aを合成素材にしても消費されなくなる。
    - **ホムンクルスの自動合成**: 
        - 触媒Aをホムンクルスに捧げると、その触媒を消費して素材Aの自動錬成を開始。
        - 触媒を重ねて与えることで、ホムンクルスによる素材Aの自動錬成速度が段階的に上昇する。
- **再創世の報酬**: 「記憶の結晶」により、錬金効率や相棒の能力を永続的に強化。
    - **錬金速度の向上**: 全体的な錬金実行サイクルの短縮。
    - **素材価値の永続向上**: 全ての錬金素材のベース価値に永続ボーナス。
    - **フェアリーの交渉術強化**: 自動売却時の手数料削減と、売却価値の永続ボーナスをアンロック。
    - **機能の利便性強化 (自動連鎖錬金)**: 
    - 通常の錬金操作に対し、錬金したい最終素材を選択して開始するだけで、不足する中間素材を自動で錬金・合成する機能をアンロック。
    - **再帰錬金の拡張**: 記憶の結晶を消費して、自動連鎖の「再帰回数」を強化可能。
        - 初期解放 (無料): 再帰回数 1
        - 拡張 (結晶消費): 再帰回数 2 以上に強化し、さらに深い階層まで一気に錬金可能に。
    - **不足素材のガイド機能**: 連鎖錬金時に素材が不足して錬金が停止した場合、錬金レシピ本（UI）にて「不足している最下層素材」を明示し、プレイヤーが採取・入手すべき目標を提示する。
    - **自動化機能の交通整理**: 
        - 競合ルール: 自動売却と自動合成は「早いもの勝ち（先に処理したプロセスが優先）」とし、プレイヤーによる複雑な優先順位設定は不要とする。
        - セーフティ機能 (在庫保護): 各素材に対して「最低保有数（安全域）」を設定可能とする。ホムンクルスの自動合成は、この最低保有数を下回る素材は消費しないようにし、自動売却も同様に保護された素材は売却対象外とする。
    - **ホムンクルス (労働力)**: 特定レシピの継続的なループ錬金。

## 4. 機能構成
| 機能 | 役割 | ゴールドの使い道 | 関連する登場人物 |
| :--- | :--- | :--- | :--- |
| **自動合成** | レシピの連続合成 | (なし) | ホムンクルス |
| **品質強化** | 素材価値の向上 | 素材加工費 | エレメンタル |
| **自動売却/粉供給** | 自動売却・粉生成 | 手数料・交渉術UP | フェアリー |
| **錬金釜強化** | 上位レシピ開放 | (なし) | 錬金釜 |
| **錬金レシピ本** | 記録・直接錬成 | (なし) | 主人公 |
| **触媒システム** | 無限利用・自動化燃料 | 触媒生成費用 | - |

## 5. 実装の方針
- **ビルド禁止**: ビルドコマンドは実行せず、コードロジックと設計による検証を行う。
- **データ駆動**: 全レシピとステータスは `recipe-db.json` に集約し、ロジックから分離する。
- **UI優先度**: アイコン主体で、直感的に「何が足りないか」が分かる設計とする。
