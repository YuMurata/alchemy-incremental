# インクリメンタルゲーム UI専門家によるレイアウトレビューと設計指針

## 1. レビュー結果と指摘事項
- **現状のUI (左サイドバー + 中央釜 + 右レシピ本)**:
    - **課題**: 操作導線が長すぎる（マウス移動量）。
    - **改善案**: 
        - レシピ本は「過去の記録（合成済みレシピのコレクション）」として機能させる。
        - 視線移動を減らすため、中央エリア（釜）の重要度を高める。
        - 相棒をUIの「数字パネル」から「ライブ演出の参加者」へ進化させる。
- **方針**:
    - 素材選択ボタンは散らさない（UX悪化を防ぐため、今の配置を維持しつつ調整する）。
    - 相棒のリアクション演出を追加する。

## 2. 実装方針 (Next Steps)
- **相棒のインタラクション拡張**: 合成成功時に各相棒がアニメーションで反応するようにする。
- **レシピ本**: 合成済みレシピのみをリスト化し、検索機能をタブ別にする準備をする。
- **レイアウトの微調整**: 釜を中心にしつつ、相棒を「UIパーツ」から「釜の横で遊ぶキャラクター」として配置し直す。
