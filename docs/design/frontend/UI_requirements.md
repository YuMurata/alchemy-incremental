# UI改善要望リスト

## 1. 合成フローの改善
- 素材を選択すると、錬金アニメーションエリア（①）に「素材A」「素材B」「素材C」および「合成開始」ボタンを表示する。
- 素材をクリックすることで選択/選択解除ができるようにする。

## 2. 将来的な拡張
- 素材のアイコン画像表示に対応する。
- 選択済みの素材箇所には素材アイコンを表示する。

## 3. アセットについて
- アニメーションや素材アイコンの生成・用意について
    - AIによる自動生成やプログラミングによる描画（p5.js等）は可能だが、ぷりんさんのこだわりを反映させるため、基本的にはぷりんさんが用意したものを組み込む形式を推奨する。
    - アイコン等のリソース管理方針を追記予定。
