# UI改善要望リスト

## 1. 合成フローの改善
- 素材を選択すると、錬金アニメーションエリア（①）に選択中の素材が表示される。
- 素材をクリックすることで選択/選択解除ができる。
- 「合成開始」ボタンを押下後、合成判定を行う。
    - 成功時: 成功結果を表示。
    - 失敗時: 失敗の旨をUI上に通知し、内部的に失敗した組み合わせとして保持する。
- 釜のエリア（中央上部）に、現在選択中の素材を表示し、ボタンで合成を実行する。レシピのヒントや結果の事前表示は行わず、あくまでプレイヤーが組み合わせを試行・探索する余地を残す。

## 2. アプグレードエリアの拡張
- アップグレードを以下のカテゴリーにタブ分割（あるいは3列表示）する。
    - ホムンクルス関連
    - 妖精関連
    - 精霊関連
- ユーザーの体験に合わせて、効果的なインフレを感じられる設計とする。

## 2. 将来的な拡張
- 素材のアイコン画像表示に対応する。
- 選択済みの素材箇所には素材アイコンを表示する。

## 3. アセットについて
- アニメーションや素材アイコンの生成・用意について
    - AIによる自動生成やプログラミングによる描画（p5.js等）は可能だが、ぷりんさんのこだわりを反映させるため、基本的にはぷりんさんが用意したものを組み込む形式を推奨する。
    - アイコン等のリソース管理方針を追記予定。
