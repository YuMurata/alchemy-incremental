# フロントエンド詳細設計書

## 1. 目的
プレイヤーが素材を収集・合成し、自動化を進めるインフレ体験のためのメインインターフェースを定義する。

## 2. 操作の優先度
- 最優先: 合成レシピのトリガー（クリック）
- 優先: 自動化生産ラインの管理（ON/OFF・レベルアップ）

## 3. 画面構成とコンポーネント構造
### 3.1 メインダッシュボード (DashboardContainer)
- **Header**: 統計情報、錬金レベル表示
- **InventoryPanel**: 
    - 素材リストをスクロール可能エリアとして配置
- **RecipePanel**: 
    - **Search & Filter Bar**: レシピ増大に対応した絞り込み機能
    - **RecipeGrid**: 合成ボタンを含むカードリスト
- **AutomationPanel**:
    - 生産ラインの稼働状況モニター

## 4. レシピ増大への対策 (拡張性設計)
- カテゴリ別フィルタリング (Basic, Intermediate, Advanced)
- 合成可能なレシピのみ表示するトグル (Show only craftable)
- 検索バーによるキーワード絞り込み

## 5. 通信仕様
- WebSocketを通じてエンジン状態を購読 (Subscribe)
- ユーザーのアクション（合成、ライン構築）はイベントとしてエンジンへ送信

## 6. 次のステップ
- このコンポーネント構造に基づき、個別のコンポーネント仕様書を作成する。
